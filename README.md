# A Fork of Storefront

[Original _Storefront_ here](https://github.com/woocommerce/storefront)

Many thanks to the creators of Storefront for their excellent work. Forking _Storefront_ allows us to design a theme on a solid foundation.

## Summary of changes
 - Stripped down:
    - Fewer dependencies
    - Fewer requests to external sites
    - Fewer bells and whistles
 - Expanded customizer:
    - Site-wide color scheme
    - Options to enable/disable features
 - Different approach to responsive design:
    - Fewer column layouts
    - More flexboxes
    - More elements which scroll on overflow
    - Fewer widgets on the side
    - Pages optimized for narrow displays

## Caution
Theme is tested with vanilla WooCommerce. Support for extensions has likely deteriorated from the original theme.
